# 🌍 星球綠化造物主（V1.9）

**小學六年級｜圓周長 × 圓面積 × 圓環面積｜多人合作星球養成遊戲**

由一位老師擔任房主，最多五名學生共同建造同一顆星球。全程為三段循序闖關：每完成一段圓周長／圓面積的數學建造任務，立即進入兩款全隊共同操作的小遊戲，合作成功才能進入下一段。六款小遊戲包含記憶、節奏、空間連接、雙核心迷宮導航、反應攔截與滑動拼圖，並非從選單中挑玩法。

> 這是**可以實際執行的第一版（MVP）**，不是只有介面設計稿。使用 Node.js 內建 HTTP + Server-Sent Events（SSE）同步，不需要下載任何第三方套件，適合以單一 Render Web Service 部署。

## 目前功能

- **1～5 位學生＋1 位房主**：房間代碼 6 碼；四人不必補齊第五人。玩家可同時作答、所有人看到同一顆星球。
- **動態建造目標**：依開始時學生數與房主設定的局數長度設定最終工程數量，三關逐步開放；玩家人數不同仍有相近工作量：

  | 學生人數 | 15 分鐘 | 25 分鐘 | 30 分鐘 |
  |---|---:|---:|---:|
  | 1 | 4 | 4 | 4 |
  | 2 | 4 | 6 | 6 |
  | 3 | 6 | 9 | 9 |
  | 4 | 8 | 12 | 12 |
  | 5 | 10 | 15 | 15 |

  **通關另外需要全隊依序完成六款操作型小遊戲（每段兩款），不能只靠一直解題。** 建議先用 15 分鐘測試，再換正式 30 分鐘局。開局時先固定該局門檻；晚加入的玩家可幫忙，但不會突然提高目標。若有人正式離房，或老師移除離線學生，系統會按剩餘人數下調目標；短暫網路斷線不會改變門檻。
- **不需要選工作站**：V1.6 正式流程移除 V1.5 的四選單式工作站與選項抉擇。階段數學目標達成後，大型合作遊戲會自動出現在全體學生與老師畫面，數學建造暫時鎖定直到共同完成。V1.7 建造計算題改為估算四選一；無須精算 π = 3.14 的長小數答案。
- **固定三段共六款小遊戲**：① 🌱 荒土甦醒：完成森林與能源數學建造 →「生命核心記憶接力」→「光能共振節奏充能」。② 💧 水土復育：乾旱減少 8 水資源，完成數學地形修復 →「旋轉水管」→「救援車 6×6 雙核心迷宮」。③ 🛡️ 文明守護：完成四類數學工程及資源目標 →「隕石攔截反應」→「星圖滑塊拼圖」。順序固定；每一個都需要隊友溝通與輪流操作，成功後才進下一階段。
- **四種數學工程、每類 10 種估算題型，另有觀念／單位／是非題（共 52 種）**：
  1. 🌳 森林：已知半徑或直徑求面積、已知面積反求半徑、森林擴建、面積比較
  2. 🛰️ 星環：已知半徑／直徑求圓周長、地表上方軌道、多圈巡航、反求半徑
  3. 🛠️ 修復：同心圓環、已知內外直徑、半環、雙坑、反推內圈半徑等十種題型
  4. ⚡ 能源：太陽能場圓面積、輸電圓周長、由面積反推半徑、環狀採集面積、雙座電站等十種題型
- **擴充題庫與避免重複**：四類工程各 10 種估算題型＋3 種觀念／單位／是非題、每類 8 組情境開場；同一題型會變動半徑、直徑、倍數等參數，學生近期 32 道完整題幹會用於避重抽題（最多重抽 28 次）。同類宇宙事件亦避免重複上一個題型。
- **估算選擇與單位觀念**：數學建造使用 π ≈ 3 的估算四選一（數值、題意與選項會輪替）；四類工程新增 km／km² 的單位觀念題，原本是非題仍保留。數學符號使用 ×、÷、-、²；長度用 km、面積用 km²。宇宙事件題與課後回顧仍可練習精算，並保留公式、數值、單位與答錯提示功能。
- **開局 0% 與能源門檻**：沒有任何建築時開發進度固定為 0%；森林、修復、能源與星環工程會即時更新共同星球的地貌與能源光效，不再把設施圖標貼在球面。側欄保留能源存量條與能源建設進度條，最終關卡仍要求能源設施數量與最低存量。
- **地貌式星球建設（V1.9）**：四類數學建造仍採 2×2 選項；不再於球體上生成樹木、衛星、修復車或閃電圖標。改由程序繪製的衛星視角卡通星球呈現：完成森林工程後長出大小不均的深淺綠林地；修復工程及水資源增加時海盆蓄水、形成湖泊與蜿蜒河流；能源工程讓地表形成區域性青綠色發光網絡；修復與穩定度提高則減少隕石坑、裂痕與灰褐色岩地。
- **真正不同的旋轉表面與稀有場景（V1.9）**：球體使用經緯度投影與多個不同形狀的大陸、海盆、陸棚和地貌紋理，約 90 秒完成一圈；每個經度的森林與水面分布不同，轉到背面不會重複前一面。透明雲層獨立緩慢飄動，球面有卡通光照與大氣邊緣，外圈軌道與小星球維持公轉。符合生態條件後不定時短暫出現櫻花盛開、鯨魚躍出、能源脈衝或極光，僅為視覺獎勵、不增減分數。支援系統減少動態效果偏好。
- **四種有動畫的事件**：☄️ 隕石墜落、☀️ 太陽風暴、🌧️ 星際生命之雨、🛸 外星探測船。每種事件各有 5 種輪替題型，同類事件再觸發不重複上一題型，並有前情說明、提示及資源獎懲。事件一發生即改變星球資源並有對應視覺異常；全隊只要有一人答對就能解除。失敗後異常會持續削減資源，必須完成對應的森林／星環／地形／能源工程來修復；不摧毀建築以避免少人局崩盤。
- **學生私有手寫計算紙**：建造題和宇宙事件題可開啟計算紙，上方固定顯示原題，滑鼠／手指／觸控筆書寫，具有畫筆、橡皮擦與清空功能。內容不會傳到伺服器，換題會清空。
- **教師即時題目與安全解答**：教師可即時看到所有學生「目前」的題目，但答案、公式與步驟預設隱藏。教師點「顯示答案」才會由伺服器針對該教師個別回傳；學生無此 API 權限。分享畫面前應先按「隱藏答案」。宇宙事件答案也同樣採按鈕顯示。
- **課後問題回顧與教學回饋**：通關或時間結束後，學生可回答 3 道圓面積／圓周長／圓環面積複習題，填寫掌握程度及文字反思。提交後顯示每題正誤、答案及步驟；老師可查看每位學生提交狀態、成績及反思，並可按「查看回顧答題詳情」顯示個人每題作答、對錯與詳解，也可再隱藏；學生無權使用教師查詢 API。成績可匯出 CSV。未提交前不會將答案傳到學生端。
- **教師節奏控制**：開始／暫停／恢復／結束／重開、題目難度、15／25／30 分鐘（單局不超過 30 分鐘），每 180 秒遊戲時間隨機觸發宇宙事件（預設開啟、可關閉），遇合作遊戲則延至結束後觸發；手動觸發或略過事件；可略過當前合作小遊戲而不給獎勵，避免課堂時間不足卡關。保留學生即時題目、解答隱藏、作答統計與 CSV。
- **斷線重連與正式退出**：單一瀏覽器會保存臨時進房憑證；只要伺服器仍在運作，可重新整理頁面接回原位置。學生按「離開房間」則釋出席位，重新加入時建立新學習統計。
- **RWD**：桌面、平板、手機皆可使用；純 HTML/CSS/JS 前端，不需建置工具。

## 更新紀錄（Changelog）

### V1.9.0 — 2026-11-12

- **修改原因**：老師要求星球具有「卡通衛星拍攝地球」的整體地貌感，不再貼著森林／能源等 emoji；從灰褐受損星球逐漸生成森林、海洋、河流及能源設施，而且不同旋轉角度應看到不同、不等面積的自然地貌，並不定時出現櫻花與海洋生物等特別景觀。
- **1｜星球視覺重製**：新增 `client/planet-renderer.js`，以純 Canvas 2D＋經緯度球面投影、具 8 組不同形狀的陸塊及多層地形噪聲，建立近似衛星視角的非寫實、卡通風格地表。依經度平滑自轉約 90 秒一圈，不再把固定大陸貼圖或 emoji 直接旋轉。不同半球的海岸線與陸地比例會不同。
- **2｜數學進度實際影響地貌**：森林建造次數＋氧氣決定不規則森林帶覆蓋程度；地形修復次數＋水資源決定海洋、湖泊及蜿蜒河流擴展；能源工程數量及能源存量決定地表發光脈絡；穩定度、修復及事件異常決定隕石坑／受損地表的殘留程度。初始以荒地、坑洞與少量水域為主，並隨遊戲逐步復甦，資源降低時也會退化。
- **3｜分離地表、雲層、大氣與軌道**：球面像素由經度查詢不同地貌、雲層以另一速度平移，球體保留明暗與柔和的大氣邊緣；原有大小兩層軌道、繞行光點及小星球公轉維持獨立動畫。以約 280×280 像素、每秒最多約 22 幀避免過度消耗裝置效能，地貌貼圖只在資源／工程狀態變化時重算；尊重 `prefers-reduced-motion`。
- **4｜稀有生態演出**：符合條件才在不固定間隔（約 18～46 秒的等待區間）出現一個持續約 6～11 秒的視覺特效：森林成熟可見粉色櫻花盛開及花瓣；海洋復甦後有鯨魚躍出和水花；能源充足時有發光波紋；大氣穩定後可出現極光。特效不涉及答題或資源獎懲，無需學生另外選擇。
- **5｜既有遊戲不變**：保留數學估算四選一、單位題、三階段六款合作小遊戲、30 分鐘上限、每三分鐘宇宙事件、教師查看即時題目及安全揭露解答、課後回顧、CSV。`client/app.js` 改為呼叫新球面 Canvas，移除球面 emoji 和外掛受損圖標；`client/style.css` 加入專用球體與大氣樣式。
- **測試與部署**：新增 `tests/planet.test.js`，驗證初始荒地、建造後森林水域能源比例成長、不同經度顯示不同地貌、異常退化及已移除球面建築圖標；擴充 `tests/integration.test.js` 確認新 Canvas 模組可被網站取得並且前端有載入。`package.json` 更新至 `1.9.0`，`npm test` 增加 Canvas 程式語法檢查。正式 GitHub Actions 和 Render 結果待合併後補記。

### V1.7.0 — 2026-11-12

- **教學需求 1｜估算四選一，數字不得固定**：原本不少題型固定半徑 5／10，容易只背答案。新增 `server/estimation-tasks.js`，四種工程共 40 種計算題型全面改為 **π ≈ 3 的估算四選一**，半徑、直徑、環帶寬度、圓圈數、建築數等隨機變化；四個選項數值彼此不同且有合理距離，學生不必精算長小數。保留概念題（四選一）及原本是非題。涉及 `server/tasks-v3.js`、`server/estimation-tasks.js`、`client/app.js`、`client/style.css`。
- **教學需求 2｜分散資訊合作，不再盲猜**：第一個合作遊戲改為「生命核心・線索接力」。2～5 人時每人各持有 **2 個位置的私人線索**，而且知道第 N 格線索的同學與要按答案的操作員不同；線索永久顯示在各自學生畫面，必須透過口頭溝通。畫面明示「先查看線索 → 持有者說出第 N 格符號 → 操作員按下」，全隊共享畫面只顯示完成進度與線索持有人，**不公開答案**。單人試玩可看到全部四個位置以免卡關。涉及 `server/team-games.js`、`client/team-ui.js`、`client/style.css`。
- **教師與資訊權限**：教師即時題目新增四個選項但預設不標示正解；只有按原本的「查看答案」才顯示正解。學生 SSE 不包含估算答案、記憶序列或其他學生的私人線索。涉及 `server/game.js`、`client/app.js`。


所有相依套件均為 Node.js 內建模組，**不需 `npm install` 也能執行**。

### 實際試玩步驟

1. 在瀏覽器 A 輸入「數學老師」→「建立我的星球房間」。
2. 在瀏覽器 B（或不同無痕視窗／手機）點「我是學生」，輸入暱稱與六碼房間代碼。
3. 可只邀請四人，甚至一人。房主先把時間調成 **15 分鐘**，降低通關門檻，按「開始任務」。
4. 學生從 2×2 建造選項選擇四種工程，計算後完成各階段任務；每個關卡完成時會自動推進。
5. 房主按「☄️ 隕石」等按鈕試看事件動畫與輪替題目；也可等待自動事件。
6. 題目解答正確，星球上會長出建築，其他學生頁面同步顯示。完成三關或時間結束後，學生填寫 3 道數學回顧題與反思；老師檢查回顧成績並匯出 CSV。

## 3. 部署 Render

1. 打開 [Render Dashboard](https://dashboard.render.com/)，點 **New → Web Service**。
2. 選擇這個 GitHub repository，branch 用 `main`。
3. 設定：
   - **Runtime / Language**：Node
   - **Build Command**：`npm install`
   - **Start Command**：`npm start`
   - **Root Directory**：留空（專案根目錄）
   - **Instance**：可先選 Free
   - **Region**：Singapore（靠近台灣，可用時）
4. 點 **Create Web Service**。Render 會提供 `https://<service-name>.onrender.com` 網址。
5. 若使用 Repo 內附的 `render.yaml`，也可以從 Render 的 **Blueprint** 流程部署。
6. 啟動後可開啟 `https://<service-name>.onrender.com/api/health`，應回覆 `{ "ok": true, ... }`。

伺服器使用 Render 提供的 `PORT`，也綁定 `0.0.0.0`，不必另外設定跨網域或 CDN。

### ⚠️ 第一版限制（上課前務必閱讀）

- **暫存不等於跨週存檔**：房間、建築與統計目前只存在 Node.js 伺服器的記憶體。Render 休眠、重啟、重新部署都可能使本局進度消失；請在課程結束前匯出 CSV。第二版才建議接 PostgreSQL 做真正的跨週養成。
- **Render Free 會休眠**：免費 Web Service 閒置後可能休眠，首次連線可能需要重新啟動。正式上課前請先打開網頁，確認服務已醒來。避免在課中部署新版本。
- **單一伺服器模式**：目前 SSE 同步與房間資料放在單一實例中；若未來要多實例橫向擴充，須改用共用資料庫／訊息佇列。
- **上課版安全性**：學生只用暱稱，沒有帳號與密碼；請不要在暱稱輸入真實敏感資料。房主權限使用每房隨機 token，避免外流。這不是正式帳號系統。
- **題庫仍是第一版**：有三種難度和隨機數值，但尚未包含完整跨週成就、每人獨立角色技能與永久科技樹。
